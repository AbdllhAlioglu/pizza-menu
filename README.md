# Pizza Menü Uygulaması 🍕

React ile geliştirilmiş modern bir pizza menü uygulaması. Kullanıcılar mevcut pizzaları görüntüleyebilir, fiyatları inceleyebilir ve sipariş verebilir.

## Özellikler

- 🖼️ Pizza resimleri ve detaylı açıklamalar
- 💰 Gerçek zamanlı fiyat bilgisi
- ⏰ Canlı saat ve çalışma saatleri bilgisi
- 🚫 Stokta olmayan ürünlerin gösterimi
- 📱 Mobil uyumlu tasarım

## Kullanılan Teknolojiler

- React 18
- Create React App
- CSS Modules
- Google Fonts (Roboto Mono)
